# Лабораторная работа № 1 на Rust

В папке находятся пять структур данных из лабораторной работы. Красно-чёрное дерево сюда не включено.

- `DynamicArray` — динамический массив строк.
- `SinglyList` — односвязный список на узлах `Box`.
- `DoublyList` — двусвязный список `LinkedList` из стандартной библиотеки Rust.
- `Stack` — стек строк.
- `Queue` — очередь строк.

## Запуск

Нужен установленный Rust и Cargo. Из этой папки выполните:

```sh
cargo run
```

Программа показывает короткий пример работы каждой структуры. Сами операции находятся в `src/structures.rs`.
