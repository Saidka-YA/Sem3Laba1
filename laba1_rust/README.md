# Лабораторная работа № 1 на Rust

В проекте каждая структура реализована в отдельном файле. Красно-чёрное дерево не включено.

- `dynamic_array.rs` — динамический массив строк.
- `singly_list.rs` — односвязный список строк.
- `doubly_list.rs` — двусвязный список строк.
- `stack.rs` — стек строк.
- `queue.rs` — обычная очередь строк.
- `double_queue.rs` — двусвязная очередь строк.
- `binary_search_tree.rs` — бинарное дерево поиска целых ключей.

Модули подключены в `src/lib.rs`, короткий пример использования находится в `src/main.rs`.

## Запуск

Из папки проекта выполните:

```sh
cargo run
```
